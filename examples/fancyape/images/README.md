Add 3 artwork files you own.

These files are served exactly as uploaded: nothing resizes, crops, recolors or re-encodes them, so give the browser files sized for the web. Name them in `../fancyape.config.js` under `gallery` (for example `image: 'my-piece.jpg'`) and set each title, artist and optional link. Use jpg, png, webp or avif. Until a file is added, the page shows an "Artwork image" placeholder frame.
